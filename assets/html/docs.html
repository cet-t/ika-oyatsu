splapi3 — Discord Embed API

Splatoon3 のスケジュール情報や武器抽選結果を Discord 埋め込み用 HTML として返す API

概要

このサービスは spla3.yuu26.com API からスケジュール情報を取得し、Discord のリンク展開（OGP）に最適化した HTML ページを返す。 URL を Discord に貼るとステージ画像・ルール名・開催時間がカード表示される。 武器抽選にも対応している。

ベースURL: https://ika.oyatsu.party

エンドポイント一覧

GET/

スケジュールの URL Builder を表示する。

GET/docs

この仕様書を表示する。

GET/open = /open/now

バンカラマッチ（オープン）の現在開催中スケジュール。

GET/open/now

バンカラマッチ（オープン）の現在開催中スケジュール。

GET/open/next

バンカラマッチ（オープン）の次回以降のスケジュール。n パラメータで何回後かを指定。

GET/regular = /regular/now

レギュラーマッチの現在開催中スケジュール。

GET/regular/now

レギュラーマッチの現在開催中スケジュール。

GET/regular/next

レギュラーマッチの次回以降のスケジュール。n パラメータで何回後かを指定。

GET/weapon

武器をランダムに抽選する。同じ武器が複数回選ばれる場合がある。

クエリパラメータ

以下のパラメータはスケジュールと武器抽選のエンドポイントで受け付ける。

名前 対象 型 説明
t スケジュール、武器抽選 u32 現状サーバー側で未使用（受理されるが出力に影響しない）
n（別名 i） /open/next, /regular/next, /weapon u8 何回先の対戦かを指定。0 = 現在開催中（now と同じ）、 1 = 次回（省略時デフォルト）、2 = 次々回。現在のスケジュールでは無視される。/weapon では抽選数を指定し、省略時は1、指定値は1〜8に収められる。
colour（別名 color, c） スケジュール、武器抽選 16進数6桁 埋め込みのテーマ色。# を付けずに指定する（例: ff8800）。省略時はルールの既定色、武器抽選では #FFFF10。

未知のパラメータや不正な値、別名を含む同一パラメータの重複指定は拒否される。 u8 は0〜255、u32 は0〜4294967295の整数。

リクエスト例

GET /open/next?n=2
GET /regular/next?i=1
GET /regular/now
GET /weapon?n=4&c=00ff00

レスポンス

Content-Type: text/html。以下の情報を含む OGP メタタグ付き HTML を返す。以下はスケジュールの内容。

項目 内容
og:site_name ika.oyatsu.party
og:title ルール名（例: ガチエリア、ナワバリバトル）
og:description 開催時間帯（MM/DD HH:MM - MM/DD HH:MM）とステージ名一覧
og:image 2つのステージ画像を結合した画像のURL
theme-color ルールに応じた色（ナワバリ: #00ff00、それ以外: #ffa500）。クエリで変更可能。

開催時間は取得元の日時の現地時刻で表示される。武器抽選ではタイトルが「武器抽選」、説明が抽選結果となり、画像は付かない。

エラー時

スケジュールの取得や画像生成に失敗した場合、または指定位置のスケジュールが存在しない場合は HTTP 500 のエラーページを返す。 不正なクエリやスケジュール名は解析時に拒否され、存在しないパスには HTTP 404 のエラーページを返す。 武器データを取得できない場合は HTTP 200 で Internal server error を返す。

対応ルール

API キー 表示名 カラー
TURF_WAR ナワバリバトル #00ff00
AREA ガチエリア #ffa500
LOFT ガチヤグラ #ffa500
GOAL ガチホコバトル #ffa500
CLAM ガチアサリ #ffa500

データソース

スケジュール: https://spla3.yuu26.com/api/{mode}/schedule
mode は regular / bankara-open のいずれか。
武器: stat.ink 武器API。
